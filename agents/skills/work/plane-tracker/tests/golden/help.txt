usage: plane.py [-h] [--json]
                {comment,link,attach,attachments,health,handoff,focus,propose-duration,create,comment-delete,comment-edit,update,get,list,search,labels,projects,whoami,report} ...

CLI de Plane CE para Agentes de IA y Reportes de Actividad (v2.3 SQLite3)

positional arguments:
  {comment,link,attach,attachments,health,handoff,focus,propose-duration,create,comment-delete,comment-edit,update,get,list,search,labels,projects,whoami,report}
    comment             Publicar comentario en un ticket
    link                Adjuntar un enlace (PR, doc) al work item
    attach              Subir archivos al work item
    attachments         Listar los adjuntos del work item
    health              Latencia y errores recientes de la API de Plane
    handoff             Imprimir el borrador del relevo (Handoff Snapshot) con
                        los hechos de git del directorio actual
    focus               Marcar en qué ticket trabaja esta sesión (reparte el
                        tiempo medido por ticket)
    propose-duration    Medir la sesión del agente y proponer una duración (no
                        registra nada)
    create              Crear un nuevo ticket / work item en Plane
    comment-delete      Eliminar un comentario (por defecto el último propio)
                        y su worklog local
    comment-edit        Editar un comentario y/o vincularle su worklog local
                        sin publicar otro
    update              Actualizar estado, prioridad o etiquetas de un ticket
    get                 Obtener detalles de un ticket
    list                Listar tickets del proyecto
    search              Búsqueda ultra-rápida FTS5 (< 2ms) de tickets en
                        Momento Cero
    labels              Listar etiquetas disponibles en un proyecto cacheadas
                        en SQLite
    projects            Listar proyectos disponibles en Plane cacheados en
                        SQLite
    whoami              Verificar configuración activa: muestra workspace,
                        usuario y UUID resuelto
    report              Generar reporte de actividades en formato híbrido con
                        Interval Merging

options:
  -h, --help            show this help message and exit
  --json                Salida en formato JSON para agentes
